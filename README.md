# website-demo

Demo website inspired by cinni.net. This repository contains a small static site (index.html, styles.css, script.js) you can edit and deploy with GitHub Pages or any static host.

How to run locally:

1. Open index.html in your browser.

How to publish with GitHub Pages:

1. Go to the repository Settings → Pages
2. Select the branch 'main' and the root folder '/'
3. Save — the site will publish at https://thatibellavic-code.github.io/website-demo/ within a minute.
